# PlayReview AI — Frontend

A React 19 + Vite single-page app: a premium, dark-mode analytics dashboard for
Google Play reviews.

## Scripts

```bash
npm run dev      # Vite dev server on http://localhost:5173 (proxies /api → :4000)
npm run build    # type-check (tsc -b) + production build
npm run preview  # preview the production build
```

The backend must be running on port 4000 (see `../Backend`). Vite's dev proxy
forwards `/api/*` to it, so there is no CORS configuration in development.

## Deployment

This frontend is configured for Vercel with an `/api` rewrite to the deployed
backend at `https://review-backend-jhau.onrender.com`. That keeps the browser
talking to the frontend origin while Vercel proxies requests to Render.

On the Render backend, set `CLIENT_ORIGIN` to the deployed frontend origin
(`https://review-frontend-three.vercel.app`) so direct browser access to the
backend remains allowed if you need it.

## Routes

- `/` — landing page with the URL input and live fetch-progress flow.
- `/app/:packageName` — the analytics dashboard. Deep-linkable and refresh-safe:
  it reads the backend cache, and if the entry is missing/expired it transparently
  re-runs the live fetch.

## Structure

Feature-based, under `src/`:

```
api/                 fetch client, SSE stream, export helpers
components/
  ui/                shadcn/ui primitives
  layout/            Navbar, BackgroundFX, StarRating
features/
  landing/           hero, URL form, feature highlights
  fetch-progress/    SSE hook + progress overlay
  dashboard/         overview cards, stat tiles, skeleton
  analytics/         all charts + validated chart color tokens
  reviews/           review cards, list (virtualized), filters, search
  export/            export menu + CSV/JSON/PDF generators
  states/            empty & error states
hooks/               useDebounce, useCountUp
lib/                 query client, formatters, URL parsing, cn
pages/               LandingPage, DashboardPage
providers/           React Query + Router + Tooltip + Toaster
```

## Design system

- Dark-mode-first tokens defined in `src/index.css` (background `#050816`, cards
  `#0F172A`, primary `#3B82F6`), Geist font, glassmorphism utilities, animated
  grid + gradient background.
- Chart colors live in `src/features/analytics/chartTokens.ts` and were validated
  for colorblind-safety and contrast against the dark card surface.

## Exports

CSV, JSON, and PDF are generated in the browser from the current **filtered**
review set. Excel is generated by the backend from the **full** cached dataset
(so the whole export runs through ExcelJS as specified). `jspdf` is loaded lazily
so it only ships when a PDF is actually requested.
